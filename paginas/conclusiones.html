Conclusiones

Lo que se vio en el curso

  • Fundamentos: antes de escribir código se piensa la solución. Un algoritmo tiene entradas, proceso y salidas; se escribe con pseudocódigo (en PSeInt) y se dibuja con diagramas de flujo.
  • Python: variables, decisiones, bucles y funciones, y con pandas, tablas de datos (Series y DataFrame) para ordenar y consultar información.
  • Desarrollo web: HTML da la estructura, CSS la apariencia y JavaScript el comportamiento. Con Canvas se dibuja en la página y con localStorage y FileReader se guardan y leen datos.
