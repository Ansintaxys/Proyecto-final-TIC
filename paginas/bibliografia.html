Para profundizar

Libros y documentación gratuita para ampliar cada tema. No son el material base del curso: son lecturas recomendadas.

  • Algoritmo, Pseudocódigo y Diagramas de flujo: Joyanes Aguilar, L. (2008). Fundamentos de programación: Algoritmos, estructura de datos y objetos (4.ª ed.). McGraw-Hill.
  • Python: Downey, A. B. (2024). Think Python (3.ª ed.). O’Reilly Media. El autor lo publica en línea (en inglés).
  • Pandas: McKinney, W. (2022). Python for data analysis (3.ª ed.). O’Reilly Media. Guía oficial: 10 minutes to pandas (en inglés).
  • JS: Canvas: MDN Web Docs, tutorial de Canvas (en inglés).
  • JS: Datos y archivos: MDN Web Docs, API de almacenamiento web y FileReader (en inglés).

Videos para aprender a hacerlo

Videos gratuitos en YouTube, en el orden en que se arma este sitio. No muestran este sitio en concreto, pero enseñan cada técnica que usa.

  1. Estructura y estilos (HTML y CSS): Cassingena Navone, E. (s. f.). Aprende HTML y CSS - Curso desde cero [Video]. freeCodeCamp.org en Español, YouTube. https://www.youtube.com/watch?v=XqFR2lqBYPs
  2. Disposición en fila (Flexbox), para el menú: Poll Sotomayor, L. (s. f.). Aprende CSS Flexbox desde cero - Curso paso a paso [Video]. freeCodeCamp.org en Español, YouTube. https://www.youtube.com/watch?v=iwFEc6I8wSA
  3. Columnas y tarjetas (CSS Grid): CSS Grid - Curso desde cero - Tutorial en español [Video]. (s. f.). YouTube. https://www.youtube.com/watch?v=n1Lnar9mTF8
  4. Efecto de alzar las tarjetas (hover, transition y transform): Aprende a usar CSS hover con transition + transform en segundos [Video corto]. (s. f.). YouTube. https://www.youtube.com/watch?v=87IXFMT6Ak8
  5. Adaptar la página al celular (diseño responsive): Choi, D. (s. f.). Crea una página web responsive con HTML y CSS [Video]. freeCodeCamp.org en Español, YouTube. https://www.youtube.com/watch?v=VgHproadDD8
  6. JavaScript desde cero: freeCodeCamp.org en Español. (s. f.). Aprende JavaScript - Curso completo desde cero [Video]. YouTube. https://www.youtube.com/watch?v=ivdTnPl1ND0 (9 horas).
  7. DOM y eventos (saludo, cambio de color, contador): Cassingena Navone, E. (s. f.). Aprende JavaScript para manipulación del DOM - Curso con proyectos [Video]. freeCodeCamp.org en Español, YouTube. https://www.youtube.com/watch?v=koiPxFFiqJ4 (5.5 horas).
  8. Dibujar en Canvas: Basanta, M. (s. f.). Practica HTML, CSS y JavaScript en español creando 7 proyectos [Video]. freeCodeCamp.org en Español, YouTube. https://www.youtube.com/watch?v=BA328RQa08M (3 horas; incluye juegos hechos con Canvas).
  9. Guardar datos en el navegador (localStorage): Curso Javascript - LocalStorage & SessionStorage [Video]. (s. f.). YouTube. https://www.youtube.com/watch?v=XpkchCqNKQ4
  10. Leer archivos de texto o CSV (FileReader): Leer o importar y exportar archivos de texto o CSV desde JavaScript [Video]. (s. f.). YouTube. https://www.youtube.com/watch?v=sFha8qWeUj4

Para el menú fijo (position: sticky) y las ilustraciones SVG no hay video en esta lista; consulta MDN: CSS position y SVG.
