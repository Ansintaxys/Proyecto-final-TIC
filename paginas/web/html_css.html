HTML y CSS

Las tres partes de una página

Lenguaje Se encarga de Ejemplo en este sitio
HTML El contenido y su estructura. Títulos, párrafos, tablas e imágenes.
CSS El aspecto. Los colores azules y los espacios, en el archivo externo estilos.css.
JavaScript El comportamiento. El saludo según la hora (java.js).

HTML: etiquetas

HTML marca el contenido con etiquetas que se abren y se cierran:

<h1>Título principal</h1>
<p>Un párrafo con <strong>negrita</strong>.</p>
<a href="index.html">Ir al inicio</a>
<img src="imagenes/flujograma.png" alt="Diagrama de flujo">
  • <h1> y <h2>: títulos.
  • <p>: párrafo.
  • <a>: enlace a otra página.
  • <img>: imagen.
  • <ul> y <li>: lista.
  • <table>: tabla.

CSS: estilos

CSS dice cómo se ve cada etiqueta. Una regla tiene un selector y propiedades entre llaves:

h1 {
  color: #1d2d44;
  font-size: 250%;
}

Esta regla pinta de azul oscuro todos los <h1> y los hace más grandes.

CSS externo e interno

Las reglas de CSS se pueden poner de dos maneras:

Tipo Dónde están las reglas Cómo se conecta
Externo En un archivo aparte, con extensión .css. Con la etiqueta <link> dentro de <head>.
Interno Dentro de la misma página HTML. Con la etiqueta <style> dentro de <head>.

Este sitio usa CSS externo: todas las páginas leen el mismo archivo estilos.css.

<!-- Externo: archivo aparte -->
<link href="estilos.css" type="text/css" rel="stylesheet">

<!-- Interno: dentro de la página -->
<style type="text/css">
  h1 { color: #1d2d44; }
</style>
  • href: dónde está el archivo CSS.
  • type: qué tipo de archivo es (text/css).
  • rel: para qué sirve el archivo (stylesheet, una hoja de estilos).

Cuando un sitio tiene más de una página conviene el CSS externo porque:

  • Todas las páginas usan las mismas reglas, sin repetirlas en cada una.
  • Separa el contenido (HTML) de cómo se ve (CSS).
  • Para cambiar el aspecto de todo el sitio se modifica un solo archivo.

Todo junto en una página

<html>
<head>
  <title>Mi página</title>
  <link href="estilos.css" rel="stylesheet">
</head>
<body>
  <h1>Hola</h1>
  <script src="java.js"></script>
</body>
</html>

El <link> trae el CSS y el <script> trae el JavaScript. Ahora puedes volver a JavaScript para ver cómo se escribe el código.
