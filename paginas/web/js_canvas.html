JavaScript: dibujar con Canvas

¿Qué es Canvas?

La etiqueta <canvas> es un lienzo en blanco dentro de la página. JavaScript le pide su contexto 2D y con él dibuja formas, texto e imágenes. Hasta ahora el código escribía texto; con Canvas el resultado se puede ver.

<canvas id="lienzo" width="300" height="150"></canvas>
<script>
  var lienzo = document.getElementById("lienzo");
  var ctx = lienzo.getContext("2d");
</script>

Formas y texto

Cada instrucción dibuja sobre el lienzo usando coordenadas: x va hacia la derecha e y hacia abajo, empezando en la esquina superior izquierda (0, 0).

ctx.fillStyle = "#3e5c76";
ctx.fillRect(20, 20, 120, 80);          // rectángulo: x, y, ancho, alto

ctx.beginPath();
ctx.arc(220, 60, 40, 0, Math.PI * 2);   // círculo: x, y, radio, ángulo inicial y final
ctx.fillStyle = "#8aa9c4";
ctx.fill();

ctx.fillStyle = "#1d2d44";
ctx.font = "20px Arial";
ctx.fillText("Hola canvas", 20, 130);   // texto: contenido, x, y

Dibujar con el mouse

El evento pointermove se dispara cada vez que el puntero se mueve (sirve con mouse y con el dedo). Si el botón está presionado (e.buttons === 1), se traza una línea desde la posición anterior hasta la actual.

var pos = { x: 0, y: 0 };

function guardarPosicion(e) {
  pos.x = e.offsetX;      // posición dentro del canvas
  pos.y = e.offsetY;
}

function dibujar(e) {
  if (e.buttons !== 1) { return; }   // solo con el botón presionado
  ctx.beginPath();
  ctx.moveTo(pos.x, pos.y);          // desde donde estaba...
  guardarPosicion(e);
  ctx.lineTo(pos.x, pos.y);          // ...hasta donde está ahora
  ctx.strokeStyle = color.value;
  ctx.lineWidth = grosor.value;
  ctx.lineCap = "round";
  ctx.stroke();
}

lienzo.addEventListener("pointermove", dibujar);

Guardar el dibujo

El método toDataURL() convierte lo dibujado en una imagen (PNG). Si se la da a un enlace con el atributo download, el navegador la descarga. Es lo que hace el botón "Guardar como imagen" de arriba.

var enlace = document.createElement("a");
enlace.href = lienzo.toDataURL("image/png");
enlace.download = "mi-dibujo.png";
enlace.click();

Animación sencilla

Una animación es repetir tres pasos: borrar el cuadro anterior, cambiar la posición y dibujar de nuevo. Con setInterval se repite varias veces por segundo. Es la misma idea del stickman: cambiar de imagen cada cierto tiempo.

var x = 30;
var dx = 4;

function cuadro() {
  ctx.clearRect(0, 0, anim.width, anim.height);   // borra el cuadro anterior
  x = x + dx;
  if (x > anim.width - 20 || x < 20) { dx = -dx; } // rebota en los bordes
  ctx.beginPath();
  ctx.arc(x, 60, 20, 0, Math.PI * 2);
  ctx.fill();
}

var reloj = setInterval(cuadro, 30);   // unos 33 cuadros por segundo
// clearInterval(reloj) la detiene

Resumen de instrucciones

Instrucción Para qué sirve
getContext("2d")Obtiene las herramientas de dibujo del lienzo.
fillRect(x, y, ancho, alto)Dibuja un rectángulo relleno.
arc(x, y, radio, 0, Math.PI * 2)Traza un círculo (luego se rellena con fill()).
fillText(texto, x, y)Escribe texto.
moveTo y lineToMueven el lápiz y trazan una línea (con stroke()).
clearRect(x, y, ancho, alto)Borra una zona; sirve para animar.
toDataURL()Convierte el dibujo en una imagen.
