JavaScript: guardar datos y leer archivos

localStorage: recordar datos en el navegador

localStorage guarda pares clave / valor en el navegador. Los datos siguen ahí aunque cierres la pestaña o recargues la página. Solo guarda texto. La portada de este sitio lo usa para recordar qué salas de práctica estaban libres o en uso.

localStorage.setItem("nombre", "Ana");          // guardar
var nombre = localStorage.getItem("nombre");     // leer (null si no existe)
localStorage.removeItem("nombre");               // borrar una clave

Para guardar más de un dato juntos (un objeto o una lista) se convierte a texto con JSON.stringify() y al leerlo se regresa a su forma original con JSON.parse():

var nota = { curso: "Python", puntaje: 15 };
localStorage.setItem("nota", JSON.stringify(nota));

var leida = JSON.parse(localStorage.getItem("nota"));
document.write(leida.curso + ": " + leida.puntaje);

Cuenta regresiva a una fecha

Un objeto Date guarda una fecha y hora. Si se restan dos fechas, el resultado está en milisegundos; dividiendo se obtienen días, horas, minutos y segundos. Con setInterval se actualiza cada segundo y con localStorage se recuerda la fecha elegida.

var fin = new Date("2026-12-15T00:00:00");
var ms = fin - new Date();                        // milisegundos que faltan

var dias     = Math.floor(ms / (1000 * 60 * 60 * 24));
var horas    = Math.floor(ms / (1000 * 60 * 60)) % 24;
var minutos  = Math.floor(ms / (1000 * 60)) % 60;
var segundos = Math.floor(ms / 1000) % 60;

0días 0horas 0minutos 0segundos

Leer un archivo con FileReader

FileReader permite leer un archivo que el usuario elige, sin subirlo a ningún servidor: se lee en su propio computador. Es parecido a pd.read_csv() de pandas, pero dentro de la página. Aquí se muestran las primeras 5 líneas, como hace head().

<input type="file" id="archivo" accept=".txt,.csv">

var lector = new FileReader();
lector.onload = function () {
  var lineas = lector.result.split("\n");
  console.log(lineas.slice(0, 5));       // primeras 5 líneas, como head()
};
lector.readAsText(archivo);              // archivo = input.files[0]

Resumen de instrucciones

Instrucción Para qué sirve
localStorage.setItem(clave, valor)Guarda un dato en el navegador.
localStorage.getItem(clave)Lee un dato guardado.
JSON.stringify() y JSON.parse()Convierten objetos y listas a texto y de vuelta.
new Date()Fecha y hora actuales; restar fechas da milisegundos.
FileReader y readAsText()Leen un archivo de texto elegido por el usuario.
