JavaScript

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que se ejecuta en el navegador. Sirve para que una página haga cosas: calcular, decidir y escribir texto. Un script es un conjunto de instrucciones que el navegador sigue de arriba hacia abajo, igual que un algoritmo.

Cómo agregar un script

Se usa la etiqueta <script>. Puede ir dentro de la página o en un archivo aparte:

<script>
  document.write("Hola");
</script>

<script src="java.js"></script>

El texto aparece en el lugar de la página donde se pone el <script>.

Comentarios

Un comentario es una nota para quien lee el código; el navegador no lo ejecuta:

// Comentario de una línea

Variables

Una variable es un espacio donde se guarda un dato, como en pseudocódigo. Se crea con var y se le da un valor con el signo = (asignación). Reglas del nombre: sin espacios, no puede empezar con un número y las mayúsculas cuentan (edad no es lo mismo que Edad).

var nombre = "Ana";
var edad = 17;
edad = edad + 1;
document.write(nombre + " tiene " + edad + " años.");

Listas (arrays)

Una lista guarda varios datos en una sola variable, entre corchetes. Se cuenta desde 0: el primer dato es la posición 0.

var notas = [15, 12, 18];
document.write("Primera nota: " + notas[0]);

Operadores

Con los operadores + - * / se hacen cálculos. El signo + también une textos.

var base = 4;
var altura = 7;
var area = base * altura;
document.write("Área: " + area);

Escribir en la página

La instrucción document.write() escribe en la página lo que lleva entre paréntesis: texto entre comillas, variables o ambos unidos con +. Es lo que usamos en los ejemplos de arriba.

El saludo de este sitio

El saludo de este sitio (panel en el Inicio y una línea en cada página) usa varias ideas de JavaScript (archivo js/java.js):

// Función que recibe la hora y devuelve el saludo
function obtenerSaludo(hora) {
  if (hora < 12) { return "Buenos días"; }
  else if (hora < 19) { return "Buenas tardes"; }
  else { return "Buenas noches"; }
}

// DOM: buscar un elemento y cambiar su texto
var saludo = obtenerSaludo(new Date().getHours());
document.getElementById("saludo-texto").innerHTML = saludo;

// Evento onclick en un botón del HTML
// <button onclick="cambiarColor()">Cambiar color</button>

// Número al azar para elegir un color de la lista
var i = Math.floor(Math.random() * colores.length);
document.querySelector("#saludo").style.backgroundColor = colores[i];

// Temporizador: repite una función cada 1000 milisegundos
setInterval(function () { segundos = segundos + 1; }, 1000);
  • Una función con return devuelve un resultado; aquí, el saludo según la hora.
  • getElementById y querySelector buscan un elemento; innerHTML cambia su contenido.
  • Math.random() da un decimal entre 0 y 1; con Math.floor() sale una posición al azar de la lista.
  • setInterval(función, milisegundos) repite una función: así el contador sube cada segundo.
  • onclick detecta el clic del botón "Cambiar color": el color solo cambia cuando lo presionas.
